# Зачёт

Онлайн-тренажёр для подготовки к зачётам и экзаменам: шесть режимов прохождения, таймер, разбор ошибок, оценка по 10-балльной шкале и отправка результатов контрольного экзамена в Google Таблицу.

Чистые HTML, CSS и JavaScript — без сборки и зависимостей.

## Возможности

- **6 режимов прохождения:**
  1. **Полный курс** — все вопросы дисциплины в случайном порядке;
  2. **Сбалансированный тест** — N вопросов, равномерно по всем темам;
  3. **Случайная выборка** — N случайных вопросов из всей базы;
  4. **Экзамен на время** — сбалансированный тест с таймером;
  5. **Тренировка по теме** — все вопросы одной выбранной темы;
  6. **Контрольный экзамен** — 20 вопросов, 30 минут, результат отправляется преподавателю в Google Таблицу.
- Два банка вопросов: «Основы ЭВМ» и «ПССИП» (по 240 вопросов).
- Иллюстрации к вопросам (PNG, JPG, WebP, SVG) с увеличением по нажатию.
- Перемешивание вариантов ответов, мгновенная проверка (режим обучения).
- Оценка по 10-балльной шкале, разбор ответов с фильтром «только ошибки».
- Тёмная тема, сохранение настроек в браузере.
- Адаптивная вёрстка для телефона и компьютера.

## Запуск

Браузер блокирует загрузку JSON при открытии файла напрямую (`file://`), поэтому нужен любой локальный сервер:

- **VS Code:** расширение *Live Server* → «Open with Live Server»;
- **Python:** `python3 -m http.server` в папке проекта → http://localhost:8000;
- **GitHub Pages:** загрузите файлы в репозиторий и включите Pages в настройках.

Либо нажмите «Загрузить JSON вручную» на главном экране и выберите файл вопросов.

## Формат банка вопросов

JSON-файл содержит объект с массивом `questions`:

```json
{
  "questions": [
    {
      "id": 82,
      "topic": "Архитектура ЭВМ",
      "question": "Текст вопроса",
      "options": ["Вариант 1", "Вариант 2", "Вариант 3", "Вариант 4"],
      "correctIndex": 0,
      "explanation": "Пояснение к ответу",
      "imagePath": "images/82.png"
    }
  ]
}
```

- `correctIndex` — номер правильного варианта, начиная с нуля;
- `imagePath` — путь к рисунку относительно `index.html` (необязательно);
- `topic` и `explanation` — необязательны.

Новый банк добавляется одной строкой в список `BANKS` в начале `app.js`:

```js
const BANKS = [
  { file: "data/questions.json", title: "Основы ЭВМ" },
  { file: "data/questions_pssip.json", title: "ПССИП" },
  { file: "data/questions_new.json", title: "Новая дисциплина" },
];
```

## Контрольный экзамен и Google Таблица

Результаты режима «Контрольный экзамен» отправляются в Google Таблицу через Google Apps Script.

### Настройка

1. Создайте Google Таблицу → «Расширения» → «Apps Script» и вставьте код:

```js
function doPost(e) {
  const d = JSON.parse(e.postData.contents);
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  if (sheet.getLastRow() === 0) sheet.appendRow(["Время (Google, Минск)", "ФИО", "Группа", "Дисциплина", "Оценка", "Результат", "Затрачено", "Время на устройстве студента"]);
  const serverTime = Utilities.formatDate(new Date(), "Europe/Minsk", "dd.MM.yyyy, HH:mm:ss");
  sheet.appendRow([serverTime, d.studentName, d.group, d.subject, d.grade, d.scoreText, d.timeSpent, d.timestamp]);
  return ContentService.createTextOutput("ok");
}
```

2. «Начать развертывание» → «Веб-приложение», доступ: «Все». Скопируйте ссылку.
3. Вставьте ссылку в `GOOGLE_SCRIPT_URL` в начале `app.js`.

### Как записывается время

Время ставит скрипт Google в момент получения ответа, в часовом поясе Минска — браузер не может узнать время серверов Google сам. Время с устройства студента сохраняется отдельным столбцом для сверки.

> Из-за политики браузеров (CORS) сайт не видит ответ Google: зелёное уведомление означает «запрос отправлен», а не «строка точно записана». Проверяйте появление строки в таблице.
